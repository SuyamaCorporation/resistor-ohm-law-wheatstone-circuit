# Ohm's Law & Wheatstone Bridge Circuit Sim
Two modes: (1) Ohm's Law calculator - input any 2 of V/I/R, calculate third. (2) Wheatstone bridge - input 4 resistors, show balance condition, calculate unknown R4 when balanced. Visual circuit diagram using SVG or canvas. Color-coded results.

## Features
- Tab-based mode switching: Ohm's Law / Wheatstone Bridge
- Ohm's Law: enter any 2 of V/I/R, calculates the missing value
- Smart unit formatting: kΩ, MΩ, μA display for large/small values
- Live SVG circuit diagram updates with calculated values
- Wheatstone Bridge: input R1, R2, R3 → calculates R4 for balance
- Balance condition formula display (R1/R2 = R3/R4)
- SVG Wheatstone bridge visual with galvanometer dashed line
- Color-coded results: cyan=voltage, purple=current, amber=resistance
- Input validation with error messages
- Accessible tabs with aria-selected and aria-controls
